**Legend:**
- `Implemented` — fact/evidence/predicate fully wired, tests pass.
- `Partial` — edges/facts exist but predicate or sufficiency missing → currently `CONFORMANT` false.
- `Unsupported` — ClassDiagrammer cannot support semantic analysis → must emit `UNSUPPORTED` per §11, not fake `CONFORMANT`.
- `Gap` — next implementation to close.

**Unsupported Scope (explicit per §11):**
`CSAS-008 Zero-Trust node boundaries`, `CSAS-010 logging field presence`, `CSAS-011 infra IaC` (no IaC files → `NOT_APPLICABLE`), `SWITCH_EXPRESSION` regex if ambiguous → `REVIEW_REQUIRED`, complex generics → `UNDECIDABLE`.
